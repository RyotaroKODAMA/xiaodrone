# xiaodrone

ESP32-S3 で動くドローン制御プロジェクトです。通常の飛行用ファームと、センサー校正用ファームを分けて運用します。

## 何が入っているか

- `src/main.cpp`
  - 飛行用の本体
  - 起動時に保存済みキャリブレーションを読み込みます
- `src/calibration_main.cpp`
  - 校正専用の本体
  - ジャイロ、姿勢オフセット、基準気圧を測って保存します
- `include/calibration_storage.h`
  - NVS に保存する共通データ定義

## キャリブレーションの考え方

この機体では、センサーは機体に固定されています。そこで、校正は飛行時とは別のファームで実行し、その結果を ESP32 の NVS に保存します。

校正時は機体を上下逆さに静置しても問題ありません。`calibration_main.cpp` 側で逆さ置きを検出し、加速度ベクトルを通常姿勢に正規化してからオフセットを算出します。

## ビルド環境

`platformio.ini` で 2 つの環境を定義しています。

- `seeed_xiao_esp32s3`
  - 飛行用
  - `src/main.cpp` をビルドします
- `seeed_xiao_esp32s3_calibration`
  - 校正用
  - `src/calibration_main.cpp` をビルドします

## 使い方

### 1. 校正を実行する

機体を静置した状態で、校正用ファームを書き込みます。

```bash
platformio run -e seeed_xiao_esp32s3_calibration -t upload
```

シリアルモニタでは、校正完了後に NVS へ保存された旨が表示されます。

### 2. 飛行用ファームを書き込む

校正が終わったら、通常の飛行用ファームを書き込みます。

```bash
platformio run -e seeed_xiao_esp32s3 -t upload
```

起動時に保存済みのキャリブレーションを読み込んで飛行を開始します。

### 3. シリアルモニタを見る

```bash
platformio device monitor -e seeed_xiao_esp32s3
```

## 保存される校正値

NVS には次の値をまとめて保存しています。

- ジャイロオフセット
- ピッチオフセット
- ロールオフセット
- 基準気圧

## 注意

- 校正用と飛行用は同じボード向けでも別環境です
- 校正をやり直したい場合は、校正用ファームを書き込んで再保存してください
- 保存先は NVS なので、通常は電源を切っても値は保持されます
